Privacy Policy

App: HyperMango  |  Last updated: May 2026  |  Hosted at: mango.yebooyah.club

Short version: HyperMango is a browser-based tool. It has no backend server. When you use it with Google Drive, it reads and writes only the specific file you open — nothing else. No data ever leaves your browser except to Google Drive on your behalf.

1. What HyperMango Is

HyperMango is a web-based multimedia stack authoring application. It runs entirely inside your browser (a GitHub Pages static site with no server-side code). Users can create, draw on, and navigate multi-card stacks, then save them as .hweb files. When accessed from Google Classroom or Google Drive, the app can open and save those files directly in the user's Google Drive.

2. Google User Data We Access

HyperMango requests the https://www.googleapis.com/auth/drive.file OAuth scope. This is a restricted, file-specific scope. It grants the app access only to:

  • Files that the user explicitly opens with HyperMango (e.g., by clicking "Open with HyperMango" in Google Drive or Google Classroom).
  • Files that the user creates through HyperMango.

The app does not request access to any other files in the user's Drive, and it cannot read, list, modify, or delete any file that the user has not explicitly chosen to open with it.

3. How We Use That Data

The Google Drive data accessed by HyperMango is used exclusively to:

  • Read the content of the file the user selects, so that the stack can be displayed and edited inside the browser.
  • Write the updated file back to Google Drive when the user explicitly clicks "Save to Drive" (or presses Ctrl+S while in Drive mode).

We do not use the data for any other purpose, including advertising, analytics, training machine-learning models, or any purpose unrelated to providing the authoring service described above.

4. How We Store and Retain Data

HyperMango has no backend server and no database. All processing happens locally in the user's browser.

  • The OAuth access token issued by Google is held in browser memory only for the duration of the current session. It is never written to localStorage, cookies, or any persistent storage by this app.
  • Stack content (card images, button data, scripts) is held in browser memory while you work. It is persisted only when you explicitly save — either to your own Google Drive or as a local file download.
  • We do not collect, transmit, or retain any user data on any server we control.

5. Data Sharing

We do not share any Google user data with third parties. The only external services the app communicates with are:

  • Google Identity Services — to authenticate the user (Google's own service).
  • Google Drive API — to read and write the user's chosen file (Google's own service).
  • Google Fonts — to load display fonts (no user data is passed; standard web-font request).

6. Children's Privacy

HyperMango is designed for educational use including K–12 classrooms. The app itself collects no personal information. All data handling is governed by Google's own policies (for Drive and Classroom integration). Schools and teachers are responsible for ensuring their use of Google Workspace for Education complies with applicable laws (COPPA, FERPA, and equivalents in their jurisdiction).

7. Google API Services User Data Policy

HyperMango's use of Google APIs complies with the Google API Services User Data Policy , including the Limited Use requirements. Specifically:

  • Data obtained from Google APIs is used only to provide and improve the in-app user-facing features described in this policy.
  • Data is not transferred to others except as necessary to provide the service.
  • Data is not used for advertising or to train AI/ML models outside the product.

8. Security

Because HyperMango has no server, there is no server-side storage to breach. OAuth tokens exist only in the browser tab's memory and are discarded when the tab is closed. Communication with Google APIs occurs over HTTPS.

9. Changes to This Policy

If this policy changes in a material way, the "Last updated" date at the top of the page will be revised. Continued use of the app after such changes constitutes acceptance of the updated policy.
